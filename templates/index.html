System Architecture

Overview of the AudioContextTransformerQA pipeline and contextual fusion mechanism.

01

Audio Input (16kHz)

STFT extraction mapping raw audio into 80 Mel-frequency channels.

02

Temporal Audio Encoder

2D Conv Stem + 4-Layer Self-Attention Transformer Encoder.

03

Cross-Attention Fusion

Question query tokens cross-attend over temporal audio frame representations.

04

Classification Head

Multi-task vocabulary decoder outputting grounded answers.

Key Implementation Details

  • Temporal Grounding: Retaining temporal frame tokens instead of global pooling preserves sequence order and exact event counts.
  • Positional Encoding: Sinusoidal frame encodings allow resolving relative temporal positions ("first", "after", "duration").
  • Synthesized Dataset: Deterministic 16kHz audio synthesis with exact timestamp annotations for reproducible benchmarking.
